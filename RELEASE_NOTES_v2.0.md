# Русификатор Baten Kaitos I & II HD Remaster v2.0

Полный русский перевод обеих игр сборника для Steam. Установщик — `BatenKaitos_Rusifikator_v2.0_delta.exe` (≈ 116 МБ).

**SHA-256:** `78afe1361092b784e48e6d64aa34bc170fcae40339996c664cf86a399d6a884d`

## Что нужно
- Лицензионная Steam-копия **Baten Kaitos I & II HD Remaster**, версия **buildid 20890367** (обе игры: Eternal Wings and the Lost Ocean и Origins).
- **Оригинальные** игровые файлы (установщик работает как набор бинарных патчей к ним и проверяет хеши). Если стоял русификатор v1.0 — сначала «Проверить целостность файлов» в Steam.
- Windows 10/11. Python и другие программы не нужны.

## Установка
1. Закройте игру. 2. Запустите установщик (первый запуск распаковывается несколько секунд). 3. «Найти автоматически» (или «Обзор…» → папка `...\steamapps\common\BatenKaitos HD Remaster`). 4. «Проверить совместимость». 5. «Установить / обновить русификатор». Установщик сохранит оригиналы в `_rus_v2` внутри папки игры.

## Удаление
Тот же установщик → «Удалить русификатор (вернуть оригинал)». Резервные копии не удаляются автоматически.

## Важно
Проверка целостности файлов в Steam и обновление игры могут вернуть оригиналы и убрать русификатор — установите заново (после обновления игры может понадобиться новая версия).

## Известные ограничения
- Часть декоративных надписей осталась английской (они нарисованы в спрайтах): итоги боя BK1 и BK2, `COMBO MAX`, `NEXT`, `Initial Time`, `TP bonus`, `HIT/HITS`, `TARGET`, `BURST`, `RELAY`, обучающие картинки справки.
- Для BK2 слова «карта/карт», «удар/ударов» имеют только две формы (одно и не одно): для чисел 2–4 грамматика неточна.
- Некоторые программно собираемые подписи могут выходить за рамку.
- Проверено автоматическими тестами на изолированных копиях и на копии автора; на других конфигурациях Windows возможны отличия.
