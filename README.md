# Русификатор Baten Kaitos I & II HD Remaster

Полный перевод текста обеих частей на русский с помощью ИИ. Иногда встречаются косяки с родами персонажей, в остальном за время теста проблем не обнаружено. Русификатор переводит текст обеих частей на русский язык.

> Язык на титульном экране выбирать не нужно: русификатор ставит русский как язык по умолчанию, другие отключаются.

## Установка

1. Установите Baten Kaitos I & II HD Remaster в Steam.
2. Закройте игру.
3. Запустите `BatenKaitos_Rusifikator.exe` и в открывшемся окне нажмите Enter.
4. Дождитесь окончания установки перевода и запускайте игру.

> Русификатор можно положить в любую папку. Игра в Steam находится им автоматически. Если установщик не нашел игру - перетащите русификатор в папку с игрой самостоятельно.

## Удаление русификатора

Запустите русификатор еще раз и нажмите `R`. Оригинальные файлы вернутся из папки `_rus_backup` внутри папки игры. Не удаляйте эту папку, если хотите откатить перевод.

## Проверка целостности

Обновление игры в Steam проверяет целостность файлов и может стереть переводы. В этом случае закройте игру, снова запустите `BatenKaitos_Rusifikator.exe` и нажмите Enter. Достаточно проделать один раз в случае обновления игры.
