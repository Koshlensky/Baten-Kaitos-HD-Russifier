# Русификатор Baten Kaitos I & II HD Remaster

Полный русский перевод обеих игр сборника **Baten Kaitos I & II HD Remaster** (Steam) и исходники для тех, кто хочет исправлять перевод или собирать свою версию.

> **Неофициальная фанатская локализация. Проект не связан с Bandai Namco Entertainment, tri-Crescendo и другими правообладателями.**
> Для установки нужна собственная лицензионная Steam-копия игры. Игровые ресурсы, английский текст оригинала, шрифты и графика игры в репозитории не распространяются.

## Для игроков

Готовый установщик — на странице **Releases** (файл `BatenKaitos_Rusifikator_v2.0_delta.exe`, около 116 МБ).

- Поддерживаются обе игры: Baten Kaitos: Eternal Wings and the Lost Ocean и Baten Kaitos Origins.
- Совместимая версия: **Steam buildid 20890367** (AppID 2146170). На других версиях установщик остановится и ничего не изменит.
- Нужны **оригинальные** файлы игры: установщик применяет к ним бинарные патчи, проверяет контрольные суммы до и после и сохраняет оригиналы в папке `_rus_v2` внутри папки игры.
- Установка: закройте игру → запустите установщик → «Найти автоматически» (или «Обзор…») → «Проверить совместимость» → «Установить / обновить русификатор».
- Удаление: тот же установщик → «Удалить русификатор (вернуть оригинал)». Резервные копии не удаляются автоматически.
- **Проверка целостности файлов в Steam и обновление игры могут вернуть оригинальные файлы и убрать русификатор** — установите заново.
- Если ставился русификатор v1.0, сначала верните оригиналы через Steam («Проверить целостность файлов игры»): установщик не пишет поверх неизвестного состояния файлов.
- Контрольная сумма и подробности — в описании релиза и в [RELEASE_NOTES_v2.0.md](RELEASE_NOTES_v2.0.md).

### Известные ограничения
- Часть декоративных надписей осталась английской: они нарисованы внутри игровых спрайтов (итоги боя BK1 и BK2, `COMBO MAX`, `NEXT`, `Initial Time`, `TP bonus`, `HIT/HITS`, `TARGET`, `BURST`, `RELAY`, обучающие картинки справки и др.).
- В BK2 слова «карта/карт», «удар/ударов» выбираются игрой только в двух формах, поэтому для чисел 2–4 они грамматически неточны.
- Подписи, которые игра собирает программно (подсказки кнопок и часть заголовков BK2), местами могут выходить за рамку.
- Установщик проверялся автоматическими тестами на изолированных копиях игры и на копии автора, но не на всех конфигурациях Windows.

### Быстрый старт: форк, правка перевода, QA и свой установщик
Нужны Windows 10/11, Python 3.12 и **собственная лицензионная Steam-копия** (buildid 20890367). Подробности и решения проблем — в [BUILDING.md](BUILDING.md).
1. **Форк и клон.** Нажмите *Fork* на GitHub, затем `git clone <адрес вашего форка>` и `cd` в папку.
2. **Зависимости.** `python -m venv .venv`, затем `.\.venv\Scripts\python -m pip install -r requirements.txt`, затем `$env:PYTHONPATH = "."`. Путь к игре инструменты ищут сами; иначе задайте `$env:BK_GAME_ROOT` (папка `...\steamapps\common\BatenKaitos HD Remaster`).
3. **Оригинальный текст из вашей копии игры.** `python -m tools.bkloc.extract` (создаёт локальную папку `source/`, она в `.gitignore` и не публикуется).
4. **Правка перевода.** Откройте нужный файл `base/matrix/<игра>/*.jsonl`, найдите строку по ID, измените поле `ru`, добавьте запись в `history` (правила — в [CONTRIBUTING.md](CONTRIBUTING.md)).
5. **QA.** `python -m tools.qa.validate_matrix`, затем `python -m tools.qa.run_qa --game bk1` и `--game bk2` (отчёты — в локальной `reports/qa/`).
6. **Сборка игровых файлов.** `python -m tools.install.full originals`, затем `python -m tools.install.full build`, затем `python -m tools.install.full verify-build` (результат в `dist/test_v2.0`).
7. **Свой установщик.** `python -m tools.release.build_release --delta` создаёт `dist/release_delta/BatenKaitos_Rusifikator_v2.0_delta.exe`; `python -m tools.release.selftest --delta` проверяет его на изолированных копиях игры.
8. **Предложить исправление.** Отправьте Pull Request: только изменённые строки матрицы (без игровых ресурсов, без папки `source/`, без собранных файлов).

### Что в репозитории
| Путь | Содержимое |
|---|---|
| `base/matrix/` | Перевод: по записи на строку, устойчивый ID (`bk1:SYS_0375`), русский текст, статус, говорящий, контекст, история правок. **Без английского оригинала** — он подставляется из вашей копии игры |
| `base/glossary/`, `base/characters/` | Глоссарий имён, мест, предметов и терминов; карточки персонажей и стиль речи |
| `base/scenes/`, `base/memory/` | Структура сцен (ID) и краткие пересказы сюжета для переводчиков |
| `tools/bkloc/` | Извлечение текстов, теги и категории, шрифты |
| `tools/qa/` | Проверки матрицы, тегов, глоссария, ширины подписей |
| `tools/install/`, `tools/gfx/` | Сборка текстовых бандлов, патчи сцен и префабов, каталог Addressables, перерисовка простых надписей |
| `tools/release/` | Установщик (окно и командная строка), сборка патчей и EXE |
| `compat/` | Хеши оригинальных файлов Steam-версии и эталонных результатов сборки |
| `prompts/`, `docs/` | Описание процесса перевода и техническая документация |
