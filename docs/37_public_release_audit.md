# 37. Аудит и подготовка публичного репозитория (D-052)

Публичное дерево собирается из рабочего репозитория командой `python -m tools.publish.make_public --out <папка> --commit` в **отдельную папку с новой, чистой историей** (один коммит). Рабочий репозиторий и его 76 коммитов не меняются. На GitHub ничего не отправлено.

## 2. История Git
- 76 коммитов, ветка `main`, remote нет. В истории есть тексты игры (`source/*`, 38 файлов) и пакеты `runs/` с английским оригиналом → **историю публиковать нельзя**; для публикации используется только новая история.
- Автор всех коммитов — реальные имя и e-mail владельца (в новой истории автор обезличен: `Baten Kaitos RU <noreply@example.invalid>`; перед публикацией при желании замените на свою учётную запись).
- Секретов (ключи API, токены) в истории не найдено; найдено 3 вхождения локального пути пользователя в старых документах — в публичное дерево не попадают.

## 5. Что нужно для публикации (делает владелец)
1. Публикация в существующем проекте идёт **без force-push** (docs/38): новая история заводится веткой `v2`, затем становится основной. Историю старого репозитория (доступа к GitHub нет, не проверялась) нужно проверить `python -m tools.publish.audit_history`: если в ней есть ресурсы игры или перевод v1.0, ветку со старой историей надо сделать приватной или создать новый репозиторий.
2. Выбрать лицензию на данные (`DATA_LICENSE.md`), при желании заменить анонимного автора коммита.
3. Войти в GitHub (`gh auth login`) и выполнить шаги из [docs/38_publishing_guide.md](38_publishing_guide.md) (публикация в `Koshlensky/Baten-Kaitos-HD-Russifier` без force-push: новая ветка `v2`, затем смена основной ветки; тег; релиз).
4. EXE в репозиторий не добавляется (расширение в `.gitignore`), только в Release; SHA-256 `78afe1361092b784e48e6d64aa34bc170fcae40339996c664cf86a399d6a884d` проверен по файлу.

## 6. Остаточные риски
- Юридические: русский перевод — производное произведение от текста Bandai Namco; патчи в установщике получены из ресурсов игры; в репозитории остались короткие названия предметов и имён в глоссарии и матрице метаданных.
