## Как устроены патчи
- Метод: zstd «patch-from» (оригинальный файл как словарь, уровень 19, окно 128 МБ, long-distance matching). xdelta3 в виде готового пакета для Windows недоступен без компиляции; zstd даёт тот же класс результата и подключается как обычная библиотека.
- Установщик перед записью проверяет SHA-256 исходного файла и самого патча, применяет патч потоком в временный файл, сверяет SHA-256 результата с эталоном и только потом атомарно подменяет файл. Оригиналы сохраняются в `_rus_v2\originals`, откат тот же, что у полного варианта.
- Порядок записи тот же: каталог первым при установке, последним при откате.
- Python не нужен; в EXE входит библиотека `zstandard`.

## Размеры патчей
- Тексты BK1/BK2: 1,5 и 3,2 МБ; шрифты: 0,15–0,29 МБ каждый; сцены и префабы интерфейса: большинство 1,2 МБ (из 19 МБ), мелкие 20–40 КБ; каталоги: 1 КБ.
- Плохо сжимаются три файла: BK2 `CAMP` — 41 МБ из 57 (71%), BK2 `NEWGAME` и `TITLEOPTION` — по 14,8 МБ, атлас боя BK1 — 15 МБ. Причина: бандлы Unity сжаты блоками, правка строки сдвигает всё дальнейшее содержимое, и блоки после неё меняются целиком.
- Можно ужаться ещё сильнее (применять патч не к сжатому файлу, а к распакованному потоку и собирать бандл заново), но для этого в установщик пришлось бы включить распаковщик и сборщик формата Unity; в этой сборке этого нет.

## Сравнение надёжности
| Критерий | Полный | Патчи |
|---|---|---|
| Работает поверх оригинала | да | да |
| Работает поверх русификатора v2.0 / прежних тестовых сборок | да (оригинал сохраняется отдельно или копируется заранее) | поверх уже установленного — да; поверх прежней сборки — только если в `_rus_v2\originals` есть сохранённый оригинал, иначе отказ с просьбой вернуть оригиналы через Steam |
| Устойчивость к повреждению данных в EXE | проверка SHA-256 каждого файла | проверка SHA-256 патча и результата |
| Требования к оригиналу | оригинал, прежняя сборка | строго оригинал (побитово), иначе патч не применится |
| Скорость и память | минимальные | читает оригинал в память (до 58 МБ) и распаковывает ≈ 500 МБ, на макете +1 с |
| Сложность | простая | больше кода, одна дополнительная библиотека |

Практически надёжность одинакова: результат обоих вариантов проверяется по SHA-256 эталона, а ошибка не оставляет файл в промежуточном состоянии. Вариант на патчах строже к исходному состоянию игры.

## Авторское право
Использование патчей не гарантирует отсутствия проблем: патч содержит изменённые данные, полученные из ресурсов игры (особенно три файла, где патч занимает 30–70% нового файла), а полный вариант распространяет изменённые ресурсы целиком. Это оценка рисков, не юридическое заключение; решение о публикации остаётся за владельцем проекта. Патчи уменьшают объём распространяемых чужих данных примерно в 5 раз, но не устраняют вопрос.

## Проверка пользовательского сценария (обе сборки)
- Окно (PrintWindow, снимки в `work/build/gui_shots*`): заголовок и все надписи по-русски; кнопки «Найти автоматически», «Обзор…», «Проверить совместимость», «Установить / обновить русификатор», «Удалить русификатор (вернуть оригинал)»; предупреждения про Steam и неофициальность на месте; строка состояния показывает «Файлов: оригинал — 45 / Совместимость: можно устанавливать».
- Сценарий на изолированной копии: проверка → установка (45/45 файлов совпадают с эталоном) → проверка → удаление (45/45 — оригинал по SHA-256) → повторная установка; сохранения и `GameAssembly.dll` не тронуты.
- Запуск самих игр на копии невозможен: макет содержит только игровые ресурсы без исполняемых файлов и без Steam-лицензии, поэтому запуск не проверялся; это можно проверить только на реальной установке.
- Замечено при просмотре: после завершения операции индикатор остаётся заполненным; на работу не влияет.
