# Проход по роду без опоры (D-037)

Дата: 19.10.2026. Основание: проверка Opus 50 строк нашла 4 серьёзные ошибки рода (безымянные говорящие, неизвестный адресат); владелец разрешил точечную проверку по правилам: сверка с оригиналом, говорящим, адресатом, карточками и контекстом; род сохраняется только при подтверждении; неизвестный род — нейтральная конструкция; ничего не правится автоматически по предупреждению линтера.

## Результат

- Проверено 185 строк (122 по первому правилу линтера и 63 по расширенному), сессии Sonnet 5.5 Medium (`gender1_01`, `gender1_02`, `gender2_01`, `gender2_02`).
- Изменено **55**, оставлено без изменений с обоснованием **130** (род подтверждён английским, карточкой или соседней репликой, либо форма относится к третьему лицу), спорных **0**. Прежние тексты — в `history[].ru_before`.
- Слабые замены для возможного пересмотра: `bk2:EV_0385` («Как же ты взрослеешь»), `bk2:EV_0202` (потерялось «сам»), `bk2:EV_0090` («Мне очень приятно» вместо «Я рада»; мать Саги подтверждена словом «Mom» в той же сцене).
- 9 замечаний Opus вне линтера рассмотрены: все 9 применены (4 как есть, 5 изменены), решения с основанием — `base/progress/opus_review50_decisions.json`.
- Полный QA после правок: BK1 и BK2 — 0 ошибок, `validate_matrix` — 0, самотесты 16/16, 19/19, 9/9.

## Почему схема пропустила ошибки и что изменено

Линтер `gender_lint` выдавал `gender_unverified`, но предупреждения не попадали в `qa_hints` редактора, а у реплик без явного «я» (`Не сомневался…`) он молчал. Исправления:
- `РОД (…)` — обязательная подсказка редактору (`tools/bkloc/units.py`);
- правило «род без опоры» с приёмами обхода — в `prompts/translator_sonnet.md` и `prompts/editor.md`;
- линтер: безличные клаузы с глаголом прошедшего времени у говорящих без карточки считаются репликой первого лица (самотест 19/19); правило намеренно узкое — без кратких прилагательных, чтобы не плодить ложные срабатывания (первая версия давала ≈ 50% ложных).
Проверки не ослаблены.
