## Главные находки

- **Где текст.** Один Unity-бандл на игру (`6a872618…` для BK1, `a8cc32bb…` для BK2); JSON-ассеты `TextIDList` и `TextData_<язык>`. CRC в каталоге не проверяется (`m_Crc: 0`).
- **Объём.** BK1 — 14 716 ID, ≈213 тыс. слов (реплики ≈175 тыс.); BK2 — 20 316 ID, ≈270 тыс. слов (реплики ≈213 тыс.).
- **Параллельные тексты.** Японский оригинал есть в обеих играх, FR/DE/ES/IT — в BK1. Это главный источник улик о говорящем.
- **Причина ошибок рода в v1.0.** Одинаковые английские строки объединены в одну запись; v1.0 переводил по английскому тексту. В BK1 у 399 таких групп в репликах разные японские строки, в BK2 — у 405. Загрузчик принимает любую группировку, поэтому v2.0 собирает русский документ по ID.
- **Говорящий.** Сцены — эмуляция скриптов GameCube (`ScriptCode_<fileId>`): реплика выводится в облачке у модели персонажа, а функция вывода не знает говорящего. В ресурсах скриптов реплики заменены маркерами `@@ID@@` (10 060 и 14 914), что позволяет восстановить точную принадлежность к скриптам (этап A, по согласованию).
- **Дух-хранитель.** BK1 умеет спрашивать пол игрока и хранит для 154 меню выбора женский и мужской варианты реплик духа (`_0`/`_1`); вопрос задаётся только в слотах jp/kr/tc/sc.
- **Теги озвучки** в японском и английском различаются (140 строк BK1) — в перевод копируются из английского.
- **Ошибки v1.0, найденные попутно:** бэкап одного шрифта BK2 не байт-в-байт (функционально тот же файл без нулевого хвоста); текстовые бандлы сохранялись без сжатия; патч ширины делает тире шире исходного.

## Ограничения

- Говорящий определяется уликами и разметкой по сцене: улики есть у 4 838 строк BK1 и 5 559 строк BK2 (около трети реплик). Остальное — разметка моделью по ходу сцены и ручная проверка спорного; часть строк уйдёт в `needs_context`.
- Порядок событий BK1 между собой и границы сцен BK2 — приблизительные (точные — после этапа A реверс-инжиниринга).
- Вместимость окон, автоперенос и пороги ширины интерфейса проверяются только в игре (этап 9).
- Назначение тегов `<kN>`, `<rN>`, `<eN>`, `<fN>` не установлено; они переносятся как есть.
- Неизвестно, какой вариант реплик духа (`_0`/`_1`) BK1 показывает в русском слоте.
- Внешние источники (вики, прохождения) на этом этапе не использовались; карточки содержат только факты из игровых данных.
