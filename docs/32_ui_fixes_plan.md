## 4. Установка и откат (по вашей команде)
```
$env:PYTHONPATH='.'
.\.venv\Scripts\python.exe -m tools.install.full status
.\.venv\Scripts\python.exe -m tools.install.full check
.\.venv\Scripts\python.exe -m tools.install.full install
.\.venv\Scripts\python.exe -m tools.install.full verify
.\.venv\Scripts\python.exe -m tools.install.full restore   # полный откат всех 40 файлов к оригиналам
```
Установка делает резервные копии в `backups/full_<время>/`, оригиналы лежат в `backups/originals_v2/`; перед записью проверяются buildid
20890367, состояние каждого файла и закрытость игр.
