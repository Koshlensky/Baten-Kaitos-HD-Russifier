# Русификатор Baten Kaitos I & II HD Remaster v2.0 — вариант на бинарных патчах (экспериментальная сборка)

Этот установщик не содержит игровые файлы целиком: внутри только бинарные патчи (zstd, база — оригинальный файл), которые применяются к оригинальным ресурсам Steam-версии **buildid 20890367**.
Функции те же, что у полного установщика: проверка версии и SHA-256 оригиналов, резервная копия оригиналов в `_rus_v2`, проверка SHA-256 результата, повторная установка, откат.

Отличия: файл примерно в четыре раза меньше; установка возможна только поверх оригинальных файлов (или поверх уже установленного русификатора). Если файлы остались от прежней тестовой сборки без сохранённых оригиналов, установщик попросит сначала вернуть оригиналы через Steam.

Использование патчей не отменяет вопросов авторского права: патч содержит изменённые данные, полученные из ресурсов игры. Решение о распространении остаётся за владельцем проекта.

Неофициальная фанатская локализация, не связанная с Bandai Namco Entertainment.
