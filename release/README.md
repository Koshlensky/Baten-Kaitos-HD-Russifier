# Русификатор Baten Kaitos I & II HD Remaster v2.0

Полный русский перевод обеих игр сборника **Baten Kaitos I & II HD Remaster** (Steam) с автономным установщиком для Windows.

> **Это неофициальная фанатская локализация. Проект не связан с Bandai Namco Entertainment, tri-Crescendo и другими правообладателями.**
> Для установки нужна лицензионная Steam-версия игры. Игровые ресурсы принадлежат их правообладателям.

## Что внутри
- Перевод текста обеих игр (диалоги, меню, предметы, справка) — около 34 тысяч строк; единая терминология по глоссарию проекта.
- Кириллические шрифты (сужение кириллицы под пропорциональную ширину).
- Русские надписи в части графики: титульные меню BK1 и BK2, экран поражения BK1, «ОЗ» в панели персонажа BK1, «ДЕЙСТВИЕ» и слова «карта/карт, удар/ударов, урона» в бою BK2.
- Исправленные подписи интерфейса (магазин, «Инфо», итоги боя BK1 и др.).
- Установщик содержит 45 игровых файлов (по два текстовых бандла, восемь шрифтов, сцены и префабы интерфейса, пять графических атласов, два каталога Addressables).

Совместимая версия: **Steam, buildid 20890367** (Baten Kaitos I & II HD Remaster, AppID 2146170). На других версиях установщик остановится и ничего не изменит.

## Установка
1. Закройте игру.
2. Запустите `BatenKaitos_Rusifikator_v2.0.exe` (Python и другие программы не нужны). При первом запуске файл распаковывается во временную папку — это занимает несколько секунд.
3. Установщик попытается найти игру сам. Если не нашёл — нажмите «Обзор…» и выберите папку `...\steamapps\common\BatenKaitos HD Remaster`.
4. Нажмите «Проверить совместимость», затем «Установить / обновить русификатор».
5. Дождитесь сообщения «Готово». Запускайте игру обычным образом через Steam.

Что делает установщик: проверяет версию игры и контрольные суммы всех 45 файлов, сохраняет оригиналы в папке `_rus_v2` внутри папки игры, записывает файлы по одному с проверкой SHA-256, затем проверяет результат. Сохранения и `GameAssembly.dll` не изменяются.

**Повторная установка и обновление.** Запуск установщика поверх уже установленного русификатора (и поверх прежних тестовых сборок v2.0) безопасен. Если установка была прервана, просто запустите её снова.

## Удаление
Откройте установщик, выберите папку игры и нажмите «Удалить русификатор (вернуть оригинал)». Файлы возвращаются из `_rus_v2\originals` с проверкой контрольных сумм. Резервные копии не удаляются автоматически; после удаления папку `_rus_v2` можно стереть вручную.

## Важно
- **Проверка целостности файлов в Steam и обновление игры могут вернуть оригинальные файлы и убрать русификатор.** После этого запустите установщик снова (после обновления игры может потребоваться новая версия русификатора).
- **Русификатор v1.0 (Grok).** Если он ставился ранее, файлы игры находятся в неизвестном состоянии, и установщик откажется их менять. Сначала верните оригинал: Steam → «Свойства» → «Установленные файлы» → «Проверить целостность файлов игры», затем запустите установщик.
- Если файлы изменены другой программой или версия игры отличается — установщик объяснит причину и не будет ничего записывать.
- Для установки нужно примерно 1,1 ГБ свободного места (копии оригиналов + новые файлы).

## Известные ограничения
- Часть декоративных надписей остаётся английской, потому что нарисована внутри игровых спрайтов, а ручная перерисовка пока не делалась:
  - BK1: итоги боя (OFFENSE/DEFENSE/RESULTS, FINAL RESULTS, DAMAGE, RECOVER, PRIZE, SP COMBO и др.), COMBO MAX, NEXT, Initial Time / SEC. / Defense Turn, Attack/Guard/Hit/Hits/Guards, названия комбинаций призов.
  - BK2: экран результатов боя (BATTLE RESULTS, EXP, TP, GOLD, TIME, MAX DAMAGE, MAX HITS), TP bonus, HIT/HITS, TARGET, BURST, RELAY, обучающие картинки справки.
- В BK2 слова «карта/карт», «удар/ударов» выбираются игрой только по двум вариантам (одно и не одно), поэтому для чисел 2–4 форма может быть «карт», «ударов».
- Многоточие «…» в BK1 заменено на «...» в русских строках; в BK2 осталось «…».
- Подписи, которые игра собирает программно (подсказки кнопок, часть заголовков BK2), могут местами выходить за рамку; известные случаи — «Макс. магия:», «Магнусы Седны» (BK2).
- Установщик проверен автоматическими тестами на изолированных копиях игры (установка, повторная установка, обновление, прерывание, откат, отказы). На реальной Steam-копии автора выполнена только проверка совместимости без записи; на других конфигурациях Windows результаты могут отличаться. Если что-то пошло не так, используйте удаление русификатора либо проверку целостности в Steam.
