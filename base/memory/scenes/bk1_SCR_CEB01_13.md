# bk1:SCR_CEB01_13 — Девушка из Цебальрая
Участники: девушка из деревни (без таблички, f), kalas, xelha
## События
- Девушка тайком встречается с парнем в Лунолестье; просит не говорить старосте (13423, 13470).
- После похода в лес староста в ярости; девушка советует Каласу держаться подальше от деревни (13538).
- Увидев Каласа со спасённой девушкой, решает, что это влюблённая пара (13677); Калас отрицает, Xelha поддразнивает его его же словами (13735, 13796).
- Позже: странные происшествия по всему Садалсууду (13911).
## Обращения
- девушка → kalas: вы; kalas → девушка: вы.
- xelha → kalas: форма обращения не установлена (после «вы» при первой встрече, D-023) — фраза без «ты/вы».
## Решения перевода
- village mayor → «староста» (proposed); «в такой ярости» для «so furious» (правка редактора).
- 13796: «Что ж, Калас, спасибо. Хорошо, что мы «просто случайно» оказались в одном месте.» — повторяет слова Каласа из 13735.
- Мысль Каласа 13851: «(Ну да… У меня есть своё дело. Мне не до того, чтобы с кем-то сближаться.)»
