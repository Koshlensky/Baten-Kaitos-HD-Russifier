# bk1:SCR_CEB06_2, CEB06_18–19, CEB02_24 — Ларикуш раскрывает прошлое Каласа (поздние сцены)
Участники: kalas, larikush, xelha, gibari, lyude, mizuti, savyna
## События
- Имя Каласу дал Гельдоблейм: «Калас» на забытом языке — «ворон», дурной знак (CEB06_2_2002).
- Ларикуш и Георг работали на Империю; первые опыты с Магнусом Конца дали силу Джакомо, Эйме и Фолону; Георг создал Каласа из изменённого магнуса — «слишком человечного», с одним крылом; затем Фи. Гельдоблейм искал «Божественное дитя» (CEB06_18).
- Двенадцать лет назад учёные бежали в Миру; Калас потерял память. Георг оставил Каласу что-то в хижине в Небесных Альпах (CEB06_19).
- Отряд поддерживает Каласа и идёт с ним в Небесные Альпы (CEB02_24).
## Обращения
- larikush → kalas: ты; kalas → larikush: вы. xelha ↔ kalas: ты. gibari, savyna → kalas: ты. Льюд → Калас: не установлено (фраза без «ты/вы»).
## Решения перевода
- Пояснение имени «ворон» связывает каламбур Гельдоблейма «хилый ворон» (TDM05B).
- Celestial Alps → «Небесные Альпы» (proposed, запасной «Небесные горы»); Iron Beetles → «железные жуки»; Kodelle → «Коделль».
- Мизути (CEB02_24_9316): титул — рабочий «Великое Мизути» (D-024), ломаная речь передана лёгкой неправильностью, без форм рода.
