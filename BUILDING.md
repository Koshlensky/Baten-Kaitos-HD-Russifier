# Сборка русификатора из исходников

Требуется Windows 10/11, Python 3.12, собственная лицензионная Steam-копия **Baten Kaitos I & II HD Remaster (buildid 20890367)**.
Игровые файлы инструментами **не изменяются**: всё читается с копированием в локальные папки (`work/`, `source/`, `backups/`).

## 1. Установка
```powershell
git clone <адрес репозитория> bk_loc ; cd bk_loc
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
$env:PYTHONPATH = "."          # запускайте команды из корня репозитория
```

## 2. Путь к игре
Инструменты сами ищут Steam-версию. Если не нашли или игр несколько:
```powershell
$env:BK_GAME_ROOT = "<путь к Steam>\steamapps\common\BatenKaitos HD Remaster"
```
Игра должна быть в оригинальном состоянии. Если на ней стоит наш русификатор, оригиналы берутся из `_rus_v2\originals` (их сохраняет установщик).

## 3. Извлечение оригинального текста
```powershell
python -m tools.bkloc.extract
```
Создаёт `source/<игра>/lines.jsonl` (английский и справочные языки, **не публиковать**) и `manifest.json`. Публичная матрица `base/matrix/` хранит только русский текст, а английский подставляется из `source/` по ID и проверяется по `en_sha1`; при другой версии игры инструменты остановятся.

## 4. Правка перевода и проверки
Строки лежат в `base/matrix/<игра>/*.jsonl` (одна запись — одна строка JSON; поле `ru`, при правке добавляйте запись в `history`). После правок:
```powershell
python -m tools.qa.validate_matrix
python -m tools.qa.run_qa --game bk1
python -m tools.qa.run_qa --game bk2
```
Отчёты — в `reports/qa/` (локально).

## 5. Сборка игровых файлов
```powershell
python -m tools.install.full originals     # сохраняет оригиналы 45 файлов в backups/originals_v2 (с проверкой хеша)
python -m tools.install.full build         # dist/test_v2.0: тексты, шрифты, сцены/префабы, каталоги, атласы
python -m tools.install.full verify-build  # повторная сборка и сверка (результат детерминирован)
```
Эталонные хеши результата для оригинального buildid 20890367 — в `compat/buildid_20890367.json` (`new_sha256`). Для шрифтов в нём же хранится метка времени выпуска (`head_modified`): сборка накладывает её, и все 45 файлов должны совпасть побайтно. Если хеши совпали, сборка идентична выпущенной; при изменённом переводе хеши текстовых бандлов, естественно, будут другими.

**Графика.** Русские надписи в спрайтах (титульные меню, экран поражения, HP/«ОЗ», ACTION, слова боя BK2) рисуются шрифтами Windows и Office: Garamond Bold, Trebuchet Bold, Segoe UI Semibold, Palatino Bold, Arial Narrow Bold (`C:\Windows\Fonts`). Эти шрифты в репозиторий не входят. Без них шаг графики не соберётся, а с другими шрифтами результат будет отличаться (хеши не совпадут с эталоном).

## 6. Свой установщик
```powershell
python -m tools.release.build_release --delta     # dist/release_delta/BatenKaitos_Rusifikator_v2.0_delta.exe
python -m tools.release.selftest --delta          # проверка на изолированных копиях игры (нужны оригиналы из шага 5)
```
Установщик содержит только бинарные патчи (zstd) к оригинальным файлам, проверяет хеши оригиналов и результата, сохраняет резервные копии и умеет откат. Полный вариант с готовыми файлами (около 480 МБ) собирается без `--delta`; в публичный релиз он не входит.

## Что нельзя воспроизвести без ваших файлов
- Английский оригинал и справочные языки — только из вашей копии игры (`extract`).
- Матрицу нельзя «перестроить с нуля» из публичных исходников: сборка `tools.bkloc.matrix build` и анализ говорящих (`tools/re`, `base/evidence`) требуют приватных артефактов и оставлены для сопровождающих. Правки перевода это не мешает.
- Хеши графики совпадут только при тех же шрифтах (см. выше).

## Типичные проблемы
- «Нет английского оригинала… выполните извлечение» — не сделан шаг 3.
- «Английский текст не совпадает с версией игры» — другая версия Steam-сборки; нужна матрица для вашего buildid (CONTRIBUTING.md, раздел «Новая версия игры»).
- «Файл игры изменён и оригинал не найден» — верните оригиналы (удаление русификатора или «Проверка целостности файлов» в Steam).
